#### Featured: [kyut0.github.io](https://github.com/kyut0/kyut0.github.io), my portfolio as a data pipeline

My resume and projects live as YAML and Markdown, and the site is built like any other
pipeline I'd ship at work:

- **Extract:** content is read from structured YAML and Markdown files.
- **Validate:** strict [pydantic](https://docs.pydantic.dev) models fail the build on a
  bad date, a misspelled field, or a role that ends before it starts.
- **Render:** Jinja templates produce the site, and [Typst](https://typst.app) compiles
  the same data into the resume and cover letter PDFs, so they can't drift apart.
- **Ship:** CI runs lint, type checks, and tests, then GitHub Actions deploys to Pages.

It also has an interactive timeline that tracks where I picked up each tool, plus color
themes generated and contrast-checked by [seedpalette](https://github.com/kyut0/seedpalette),
my open-source palette tool.
